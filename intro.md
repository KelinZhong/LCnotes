# LeetCode Prep Notes

Study guides, cheat sheets and references for coding-interview practice in Python and SQL.

To read other notes, visit [Study Notes](https://kelinzhong.github.io/StudyNotes/).

## Where to start

**If you have a problem in front of you and don't know what it is**, open the
[Decision Guide](Python%20LeetCode/01_decision_guide.ipynb). It routes an unseen problem to a
pattern from its constraints and wording — everything else in this book assumes you
already know the topic.

**If you're learning a topic**, work down the Python chapters in order. File numbers
follow the suggested learning order, easiest first.

## The three kinds of notebook

Every notebook carries one of these labels under its title.

| Label | What it does | When to open it |
| :--- | :--- | :--- |
| **Study Guide** | Teaches the concept from scratch with explanations, comparisons and worked examples | Learning a topic for the first time — read it linearly |
| **Cheat Sheet** | Assumes you know the topic; gives the template, decision rules and common mistakes | Reviewing before an interview |
| **Reference** | Flat lookup, no prose | Mid-problem, when you need one specific trick or method |
